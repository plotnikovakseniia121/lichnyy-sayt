# План разработки профессионального сайта Ксении Плотниковой

## Основа плана

План относится к первому выпуску сайта по `tz.md`: одна русскоязычная адаптивная страница в трёх файлах `index.html`, `styles.css`, `script.js`. Факты, цифры, услуги и кейсы берутся только из `Позиционирование_для_личного_сайта_Ксения_Плотникова.md`; более поздние прямые формулировки Ксении в чате имеют приоритет для тех элементов, которых они касаются. Сайт Lovable используется только как визуальный и композиционный ориентир.

В текущий объём не входят публикация сайта, полноценная английская версия, база данных, сервер, форма заявки, аналитика, цены и дополнительные страницы.

#### Визуальная система

**Композиция первого экрана**

- Фон — тёмно-зелёный.
